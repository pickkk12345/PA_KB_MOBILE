# Rekomendasi Mata Kuliah - Sistem Akademik Mahasiswa

Aplikasi mobile berbasis Flutter yang membantu mahasiswa mendapatkan rekomendasi mata kuliah berdasarkan performa akademik mereka. Sistem ini menganalisis data kehadiran, nilai UTS, nilai UAS, dan aktivitas partisipasi mahasiswa untuk menghasilkan rekomendasi mata kuliah yang sesuai dengan kemampuan dan performa belajar. Backend menggunakan FastAPI dengan database SQLite yang memproses 5000+ data mahasiswa dan performa akademik. Aplikasi ini dirancang untuk memudahkan mahasiswa dalam merencanakan jadwal kuliah semester berikutnya dengan lebih optimal berdasarkan track record akademik mereka.
